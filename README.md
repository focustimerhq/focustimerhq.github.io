# Focus Timer website

Website for [Focus Timer](https://github.com/focustimerhq/FocusTimer) project. Built as a static site with [Eleventy](https://www.11ty.dev/) (Nunjucks + SCSS), deployed to GitHub Pages.

## Development

Requires Node.js 22+.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is written to `_site/`.
