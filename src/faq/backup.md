---
question: Backing up data
order: 8
---

Your data is stored in `~/.var/app/io.github.focustimerhq.FocusTimer/data/focus-timer/database.sqlite` (if you're using Flatpak) or `~/.local/share/focus-timer/database.sqlite`. The file is automatically backed up daily in the same directory and automatically restored in case the database gets corrupted.
